# Accessibility For Everyone

This is the source code for the web site at https://accessibilityforeveryone.site, which contains a freely readable copy of [Laura Kalbag](https://laurakalbag.com)’s book, Accessibility for Everyone.

The book is published by [Small Technology Foundation](https://small-tech.org) and the site is written in [Kitten](https://kitten.small-web.org).
